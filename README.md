# James Notes · public website

This repository is the **public deployment destination** for [James Notes](https://james-chi-jie.github.io/).

- The private `personal-blog` repository contains the original Markdown, figures, notes, article plans, and Astro source code.
- This public repository must contain **only the generated static site** (HTML, CSS, JS and approved public images) on the `gh-pages` branch.
- Never copy private drafts, `AGENTS.md`, `plan.md`, `state/`, private GitHub secrets, or unreleased assets here.
- Publication happens only via the manually-triggered release workflow in `personal-blog` after explicit author approval.
- The `main` branch holds deployment documentation; Pages will serve `gh-pages` from the repository root.

## One-time Pages setup

In **Settings → Pages → Build and deployment**, select **Deploy from a branch**, then `gh-pages` / `(root)`. The branch will exist after the first successful publishing workflow run.
